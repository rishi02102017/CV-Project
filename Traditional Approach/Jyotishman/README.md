# Traditional Lane Detection using Hough Transform 🚧

This Streamlit app performs traditional lane detection on road images using:
- **Canny Edge Detection**
- **Hough Line Transform**

You can upload an image or video, tune detection parameters, and view results side-by-side or overlaid.

## Features:
✅ Canny & Hough detection  
✅ Slider control for parameters  
✅ Overlay and side-by-side comparison  
✅ Support for videos (frame-by-frame)

## Run Locally:
```bash
pip install -r requirements.txt
streamlit run app.py
```
